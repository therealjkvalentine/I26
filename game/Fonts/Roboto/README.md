# Roboto Bold

The font the modern look draws the cockpit's ammunition counter digits with (`game/Scripts/Sim/CounterDigits.cs`): of the
free faces tried against the original's 8-pixel counter strip (znbe), its figures matched best (the flagged 1 without a
foot, the closed 4, the straight 7, the round 6 and 9, about 0.65 as wide as high, the weight of the strip's strokes),
as the grotesque figures on mechanical counter wheels do.

**Its licence is not the project's.** Roboto is Copyright 2011 The Roboto Project Authors, under the SIL Open Font
License 1.1, in `OFL.txt` beside it. `Roboto-Bold.ttf` is the static Bold from the Roboto 3.016 release
(https://github.com/googlefonts/roboto-3-classic/releases, `android/static/Roboto-Bold.ttf`), unchanged; `OFL.txt` is the
licence text from https://github.com/google/fonts (`ofl/roboto/OFL.txt`). The release ships the licence text with the
game (`tools/release.sh`).
