# Label-tape face candidates (not shipped)

Faces of the Impact Label genre (label-maker / embossed-tape lettering), gathered for choosing the weapon labels' face.
The font files are not in the repository (several are free for personal use only, and the repository is public):
download them from the sources below into this folder (ignored by git) to try them, for example with
`I76_DYMO_FONT=path.ttf` (docs/dev-hooks.md). The maintainers' copies, each with the licence or readme its download
ships (else a SOURCE.txt recording the listing), are kept outside the repository. The labels are lettered by `DymoLabels.Paint` (the game paints the tape itself), so only
letters-only faces fit as they are; the tiled faces (the tape drawn into each glyph) are kept for comparison.
